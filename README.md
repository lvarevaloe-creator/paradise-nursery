# Paradise Nursery Shopping Application

Paradise Nursery is an e-commerce React application designed for plant lovers. It allows users to browse various categories of indoor plants, view details, add items to a shopping cart, and manage cart quantities in real-time using Redux Toolkit.

## Features
- Landing Page with company details and background image.
- Categorized Plant List with 6+ plants across 3 categories.
- Real-time shopping cart count and dynamic cost calculation.
- Redux Toolkit state management for adding, updating, and removing items.# paradise-nursery
